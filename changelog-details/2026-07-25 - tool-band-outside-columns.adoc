= Tool band outside the 3-column group

== Problem

Search lived in the left nav column (`.valentus-nav-search` inside `.nav-panel-menu`). That panel uses `overflow-y: auto`, so the Lunr results dropdown was clipped at the column boundary.

`valentus-read-width` sat inside `article.doc` in the center column, so the control was part of the 3-col measure rather than a chrome tool above it.

== Fix

Introduce `.valentus-shell` wrapping:

* `.valentus-tool-band` — full shell width above the columns: search (left, nav-width) + read-width (centered over the doc column) + TOC-width spacer
* `.body.valentus-body` — peers only: `nav | main | TOC`

Search keeps `/` focus shortcut and the `/` hint badge. Equal `--valentus-side-width` for nav/TOC is unchanged. Tool-band ancestors use `overflow: visible` and a raised `z-index` so the dropdown can paint over the columns.

== DOM (desktop)

----
.valentus-shell
  .valentus-tool-band
    .search.valentus-nav-search.valentus-tool-search
    .valentus-tool-band-center > .valentus-read-width
    .valentus-tool-toc-slot
  .body.valentus-body
    .nav-container > … > nav.nav-tree-only
    main.valentus-article > … > article.doc
    aside.toc.sidebar
----
