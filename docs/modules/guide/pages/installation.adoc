= Installation
:navtitle: Installation
:description: Install Valentus Theme: release UI bundle plus the chassis color-scheme extension.

== Release UI bundle (recommended)

**Use `ui-bundle.zip` from GitHub Releases.** One pinned `ui.bundle.url` for the chrome and paint, plus the `@antora-supplemental/color-scheme` extension for the light/dark mechanism.

Successor to the former `antora-dark-theme` package — migrate playbook URLs to Valentus.

* link:https://github.com/antora-supplemental/valentus-theme/releases[GitHub Releases]
* link:https://antora-supplemental.github.io/docs/[Antora Supplemental docs portal] (extensions registry)

== Steps

. Configure `antora-playbook.yml`:
+
[source,yaml]
----
ui:
  bundle:
    url: https://github.com/antora-supplemental/valentus-theme/releases/download/v3/ui-bundle.zip
    snapshot: true
antora:
  extensions:
    - require: "@antora-supplemental/color-scheme"
      toggle: placed
----
+
and in `package.json` devDependencies:
+
[source,json]
----
"@antora-supplemental/color-scheme": "github:antora-supplemental/antora-ui-chassis#color-scheme-v0.1.2&path:packages/color-scheme"
----

For floating, line-pin, dual-axis labels (`2.0.0+antora.3`), or Renovate strategies see xref:version-pinning.adoc[Version Pinning].

. Optional branding—*one* override directory:
+
[source,yaml]
----
  supplemental_files: ./supplemental-ui-overrides
----

. Build:
+
[source,bash]
----
antora antora-playbook.yml
----

Pin `releases/download/v3/ui-bundle.zip` (rolling Valentus major 3) or an exact `vX.Y.Z` in CI when you need bitwise stability.
Stay on `v2` until you port supplemental overlays for the 3.0.0 `valentus-*` hook rename; stay on `v1` for the pre-redesign line.

After you adopt the bundle, add the GitHub repository topic `valentus-theme` on the playbook repo so dependents stay rediscoverable — see xref:github-topics.adoc[GitHub Topics].

[[migrate-from-antora-dark-theme]]
== Migrate from `antora-dark-theme`

Replace:

[source,yaml]
----
ui:
  bundle:
    url: https://github.com/antora-supplemental/antora-dark-theme/releases/.../ui-bundle.zip
----

With:

[source,yaml]
----
ui:
  bundle:
    url: https://github.com/antora-supplemental/valentus-theme/releases/download/v3/ui-bundle.zip
    snapshot: true
antora:
  extensions:
    - require: "@antora-supplemental/color-scheme"
      toggle: placed
----
+
and in `package.json` devDependencies:
+
[source,json]
----
"@antora-supplemental/color-scheme": "github:antora-supplemental/antora-ui-chassis#color-scheme-v0.1.2&path:packages/color-scheme"
----

Remove `antora-dark-theme` from `package.json` if present; use the release bundle URL or `pnpm add -D valentus-theme` for supplemental vendoring.

Canonical homes are the **antora-supplemental** org repositories (`valentus-theme`, `antora-ui-chassis`). `antora-dark-mode` is deprecated.
Personal forks of the old `antora-dark-theme` name are obsolete — do not pin them.
Old dark-mode migration copy: link:https://antora-supplemental.github.io/antora-dark-mode/antora-dark-mode/guide/legacy-names.html[Legacy names & migration^].

[[overrides-on-bundle]]
=== Overrides

Logo, favicon, or a few partials in a single directory (for example `supplemental-ui-overrides/`).
See xref:configuration.adoc#virtual-supplemental-files[virtual supplemental files] for single-file entries.

== Vendor `supplemental-ui` (forks)

Copy `supplemental-ui/` from this repository into git for a maintained fork.
There is no vendored dark-mode copy; keep the `@antora-supplemental/color-scheme` extension in the playbook.

== Verify

Open the built site and use the sun/moon navbar toggle; preference should persist across pages.
