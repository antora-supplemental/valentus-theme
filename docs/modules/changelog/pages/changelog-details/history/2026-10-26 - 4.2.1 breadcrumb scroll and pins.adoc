= 4.2.1 — breadcrumb scroll and chassis pins
:page-date: 2026-10-26

== What shipped

* b375fdd: the mast breadcrumb stays on one line and scrolls sideways with no visible scrollbar. A CSS `mask-image` fades each edge on its own whenever text is hidden past it. The trail scrolls to the end on load and again after SoftNav swaps. It can be reached with the keyboard and respects `prefers-reduced-motion`.
* 73ca5c8: 4.2.0 shipped with the old chassis pins (color-scheme-v0.4.0). 4.2.1 pins `color-scheme-v0.5.3` and `light-dark-mode-v0.1.3`, with the lockfile updated.

== Release

Git tag `v4.2.1`, public label `4.2.1+antora.3`. The release workflow builds `ui-bundle.zip` and `valentus-layout-bundle.zip`, moves the `v4` and `v4.2` lines, and adds the `v4.2.1+antora.3` tag.
