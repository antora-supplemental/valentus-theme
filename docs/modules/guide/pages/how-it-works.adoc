= How It Works
:navtitle: How It Works
:description: How Valentus layers chassis, paint and body kit on the Antora Default UI.

Valentus overlays the Antora Default UI bundle with supplemental files; the color scheme mechanism is the chassis Antora extension `@antora-supplemental/color-scheme`.

== Layers

[cols="1,3",options="header"]
|===
| Layer | What

| Chassis — `@antora-supplemental/color-scheme`
| Inline head hook (no FOUC): reads `antora-theme-mode`, sets `html.dark-theme`, `data-theme`, `data-color-scheme-mode`. `js/color-scheme.js`: persistence, live system preference, override expiry, View Transition crossfade, toggle binding and a11y, `window.ColorScheme` API, SoftNav rebinding. `css/color-scheme.css`: `color-scheme` property and transition rules. No colors.

| Paint — Valentus
| Valentus Paint (`paint/css/valentus-paint.css`): `--cs-*` light/dark token values, Default UI and content colors, toggle look. The layout reads only tokens.

| Body kit — Valentus
| Partials: header (places `#theme-toggle`), mast, layout, footer.
|===

== head-meta.hbs

. Applies the interim paint-hold (`html.valentus-fouc-pending`)
. Loads the Valentus stylesheet chain (paint slot, `valentus-chrome`, `site-doc-layout`, `site-visual`, `site-read-width`, `site-font-size`, `site-math`)
. Maps `site.keys.darkModeNavbar` to `html[data-dm-navbar]`, runs read-width / font-size FOUC scripts and releases paint after webfonts

The color scheme head hook is injected by the extension right after `site.css` (in `head-styles`), so it runs before any Valentus CSS.
Hub overrides must keep the full chain — see xref:customization.adoc[Customization].

== footer-scripts.hbs

Loads `site.js`, highlight.js and Valentus scripts (accordion, visual, read-width, font-size, math, …). The extension appends `js/color-scheme.js` (deferred).
Hubs that override footer partials must **not** load `site.js` (or these Valentus scripts) a second time.

== Sequence of events

. `<head>`: `site.css`, then the color scheme hook sets `html.dark-theme` before first paint
. Valentus CSS loads with the right scheme already applied
. Footer: `color-scheme.js` binds the placed `#theme-toggle`
. Toggle click: `ColorScheme.toggle()` persists `antora-theme-mode` and crossfades
