= Changelog

All notable changes to this project will be documented in this file.

The format is based on https://keepachangelog.com/en/1.1.0/[Keep a Changelog],
and this project adheres to https://semver.org/spec/v2.0.0.html[Semantic Versioning].

== Version identity (dual-axis)

Public labels use **`VALENTUS_SEMVER+antora.N`** (example: `2.0.0+antora.3`).

* *Valentus semver* (`MAJOR.MINOR.PATCH`) — chrome/partial/CSS contract for theme modders. Lives in `package.json` and git tags `vX.Y.Z`.
* *`+antora.N`* — Antora *framework* major this release targets. Does **not** bump Valentus major by itself.
* Git tags stay pure semver (`v2.0.0`). Release titles and this changelog use the full label.
* Historical **1.x** releases were all Antora 3 → documented as `1.x.y+antora.3`. Existing tags (`v1.0.0`, …) were **not** renamed.

== [2.0.0] - 2026-07-25

Ask defaults off → struck *or Ask*. Phase 1: compound CSS/markup stub; Ask tabs transitional. See `packages/antora-search-chat/ARCHITECTURE.adoc`.

* See link:changelog-details/2026-07-25%20-%20antora-search-chat%20scaffold.adoc[Detailed notes — 2026-07-25 antora-search-chat scaffold].
* *Fix:* Double-click / triple-click can select text in `#search-input` again when search sits under `.nav-panel-menu`. Antora UI default `site.js` calls `preventDefault` on multi-click `mousedown` in the nav panel (to avoid selecting nav labels); Valentus stops that event at `#search-field`. Also set `user-select: text` on the search input. Tool-band search is outside the panel; search-chat keeps the same guard when present.
