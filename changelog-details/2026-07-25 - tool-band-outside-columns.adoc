= Tool band outside the 3-column group

== Problem

Search lived in the left nav column (`.adt-nav-search` inside `.nav-panel-menu`). That panel uses `overflow-y: auto`, so the Lunr results dropdown was clipped at the column boundary.

`adt-read-width` sat inside `article.doc` in the center column, so the control was part of the 3-col measure rather than a chrome tool above it.

== Fix

Introduce `.adt-shell` wrapping:

* `.adt-tool-band` — full shell width above the columns: search (left, nav-width) + read-width (centered over the doc column) + TOC-width spacer
* `.body.adt-body` — peers only: `nav | main | TOC`

Search keeps `/` focus shortcut and the `/` hint badge. Equal `--adt-side-width` for nav/TOC is unchanged. Tool-band ancestors use `overflow: visible` and a raised `z-index` so the dropdown can paint over the columns.

== DOM (desktop)

----
.adt-shell
  .adt-tool-band
    .search.adt-nav-search.adt-tool-search
    .adt-tool-band-center > .adt-read-width
    .adt-tool-toc-slot
  .body.adt-body
    .nav-container > … > nav.nav-tree-only
    main.adt-article > … > article.doc
    aside.toc.sidebar
----
