== [Unreleased]

* *Fix:* Mouse wheel over the left nav or in-page TOC scrolls the page again. Default UI sets `overscroll-behavior: none` on those panels, which trapped the wheel when the panel had nothing left to scroll; Valentus restores scroll chaining.
* See link:changelog-details/2026-07-25%20-%20sidebar%20wheel%20scroll%20chaining.adoc[Detailed notes — 2026-07-25].

== [1.1.2] - 2026-07-24

* *Header logo:* Brand-first dark mode — no unconditional invert on `.adt-header-logo`. Colored marks stay as authored; opt in with `site.keys.header_logo_tone: mono` for silhouette marks.
* *Header logo:* Optional light/dark asset pair via `site.keys.header_logo_dark` (CSS swap on `html.dark-theme`). Valentus ships an anatomical heart outline (`logo.svg` / `logo-dark.svg`) and enables the pair on demo playbooks.
* *Fix:* UI partials read camelCased `site.keys` (`headerLogoDark`, `darkModeNavbar`, …). Snake_case lookups never matched Antora's UI model, so playbook branding keys were ignored.
* *Docs:* Guide page `header-logo.adoc` with brand/mono fixture mocks so single-file strategies are documented without a second logo in the live chrome.
* See link:changelog-details/2026-07-24%20-%201.1.2%20brand-first%20header%20logo.adoc[Detailed notes — 2026-07-24].

== [1.1.1] - 2026-06-13

* *Dark-mode toggle:* Default `site.keys.dark_mode_navbar` to `light` so the theme toggle uses a dark icon on Valentus' light top bar; vendors `antora-dark-mode` v1.3.1 navbar-tone support.
* *CI:* Fix Release workflow `matches()` guard, dynamic antora-dark-mode pin from `antora-playbook.yml`, `workflow_dispatch` re-publish.

== [1.1.0] - 2026-06-13

* *Bundled dark mode:* Release `ui-bundle.zip` merges link:https://github.com/antora-supplemental/antora-dark-mode[antora-dark-mode] with Valentus chrome. Successor install path for former `antora-dark-theme` consumers.
* *Partials:* `head-meta.hbs` and `footer-scripts.hbs` include FOUC prevention, `site-extra.css`, and `site-dark-mode.js`.
* *Maintainers:* `pnpm dark-mode:sync` vendors dark mode CSS/JS from `antora-dark-mode`; release CI runs sync before bundling.

link:changelog-details/2026-06-13%20-%201.1.0%20bundled%20dark%20mode.adoc[Detailed notes — 2026-06-13]

== [1.0.0] - 2026-06-09

* Initial release: doc-site chrome split from `antora-dark-theme` into `valentus-theme` (mast, header, layout, VCS icons, UI modules orchestrator).
* Pair with link:https://github.com/antora-supplemental/antora-dark-mode[antora-dark-mode] for dark styling and the theme toggle.
* GitHub Pages demo via `.github/workflows/deploy.yml`.
