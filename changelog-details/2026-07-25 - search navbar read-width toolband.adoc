= Detailed notes — 2026-07-25 search navbar + read-width tool band

== Summary

Correct placement for command-palette search vs page layout control after 2.0.0 shipped with both controls sharing `.valentus-tool-band` (search sized to the nav column).

== Placement

* *Search* (compound omnibox + scope) → center of `.valentus-site-navbar` (`.valentus-navbar-search`). Own width (`min(36rem, …)`), not `--valentus-nav-width` / `--valentus-doc-max`.
* *Read-width* → stays in `.valentus-tool-band` center over the doc column.

Prior “search over nav / resize over doc” in the tool band was inverted for a site-wide command-palette search.

== Scope dropdown

* Explicit `--valentus-ink` / `--valentus-elevated` (and dark-theme mirrors) so closed select and `option` list are not light-on-light.
* Extra `padding-inline-end` + `min-width` so “This component” is not clipped by the custom chevron.
