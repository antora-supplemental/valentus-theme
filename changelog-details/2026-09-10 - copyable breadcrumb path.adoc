= Copyable breadcrumb path characters
:description: Replace CSS slash separators and the home SVG chip with real characters so the mast copies as a path for pasting into AI or notes.
:page-audience: Theme maintainers and readers who copy location chrome
:page-usage-context: After rebuilding against Valentus 2.0.28+
:page-orig-author: Ryan Johnson
:page-last-author: Cursor agent on behalf of Ryan Johnson
:page-last-edited: 2026-09-10

== Context

Pseudo-element `/` separators and an SVG home icon do not survive a text selection. Readers (and agents) want to drag-select the mast and paste something like `/ Home ~ / Where docs live`.

== Changes

* Site home control renders the character `/` (aria-label still “Site home”); drop the kicker chip chrome — muted at rest, accent on hover/focus.
* Trail separators are `<li class="adt-breadcrumb-sep">/</li>` text nodes (CSS `::after` separators disabled).
* A real space sits between the component and version kickers so a selection reads `Home ~` instead of `Home~`.
* Leading `/` is the site root; additional `/` characters only appear before trail segments (no doubled slash after home).
