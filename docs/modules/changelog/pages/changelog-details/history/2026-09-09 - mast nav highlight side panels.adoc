= 2.0.19 — mast, nav highlight, side panels, in-doc TOC
:navtitle: 2.0.19 mast nav TOC panels
:description: Valentus 2.0.19 UX: version control modes, link-style kickers, nav highlight clip/fade, optional side panels, muted in-doc TOC.

== Summary

Mast version control is mode-aware (`hide` / `plain` / `menu`). Kickers look like links until hover. Nav current-row highlights clip with overflowing labels. Side-rail panel wash is optional in light mode (`valentus-side-panels`). In-doc TOC is styled as its own muted block, separate from page-context metadata tables.

== Options

* `html.valentus-side-panels` / `body.valentus-side-panels` / `html[data-valentus-side-panels=true]` — enable light-mode nav/TOC panel wash (`--valentus-side-panel-bg`).
* `--valentus-side-panel-radius` (default `2px`), `--valentus-side-panel-pad`, `--valentus-nav-scroll-fade`.
