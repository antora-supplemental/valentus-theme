= FOUC paint-hold (interim) until upstream single-pass CSS

* *Symptom:* Refreshing a Valentus site (especially with brand/overrides layered after the bundle) shows a brief “settle” as Default UI `site.css` paints, then supplemental `site-extra` / layout / visual / read-width / font-size CSS reflows the chrome.
* *Hack:* `head-meta.hbs` adds `html.adt-fouc-pending { visibility: hidden }` until stylesheet links have loaded and preference FOUC scripts (`dark-theme`, `data-adt-read-width`, `data-adt-font-size`) have run. **2.0.13+** also waits for Valentus web fonts (see link:changelog-details/2026-08-20%20-%20font%20fouc%20paint-hold.adoc[font FOUT hold]) before removing the class. Stylesheet `<link>`s are listed before those scripts so the release script waits on the cascade.
* *Pending upstream:* Prefer compiling theme/layout tokens into Default UI `site.css` (no post-`site.css` layout cascade). Dark-mode FOUC contract tracks https://gitlab.com/antora/antora-ui-default/-/merge_requests/207[!207]; supplemental-cascade guidance: https://gitlab.com/antora/antora-ui-default/-/merge_requests/213[!213]. Remove this hold when first paint no longer depends on layered supplemental CSS.
* *Consumers:* Sites that *override* `partials/head-meta.hbs` must copy this pattern (or stop overriding and take the bundle partial). Brand CSS links should stay with the other stylesheets, before the paint-hold release script.
