= Descender clip on page title and breadcrumbs

* *Symptom:* Lowercase descenders (g, p, y) were cut off below the baseline on page titles (`.adt-page-title`), breadcrumb trail text, and component/version kickers — especially visible with custom display fonts (Syne on HCI Nerdz docs).
* *Cause:* `site-doc-layout.css` paired `overflow: hidden` with tight `line-height: 1.2` on single-line ellipsis targets. The overflow box matched the line box height, so descenders extending below the baseline were clipped.
* *Fix:* Raise line-height (1.3 page title, 1.5 trail, 1.45 kicker), use `overflow-x: hidden; overflow-y: visible` for horizontal ellipsis without vertical clip, and set `line-height: 1.35` on the narrow `-webkit-line-clamp: 2` title rule.
* *Files:* `site-doc-layout.css` in `supplemental-ui` and `ui-modules/packages/doc-layout`.
