= 1.1.2 — brand-first header logo (pair, brand, mono)

::navtitle: 1.1.2 header logo strategies

* *Breaking assumption fix:* Dark mode no longer applies `filter: brightness(0) invert(1)` to every `.adt-header-logo`. That filter was for the old `currentColor` placeholder loaded via `<img>` and flattened colored brand marks (they looked blank or washed out).
* *Default single-file:* Brand / colored logos render as authored in light and dark (`header_logo_tone` default `brand`). No light+dark asset pair required when the mark already has contrast.
* *Opt-in mono:* `site.keys.header_logo_tone: mono` adds class `adt-header-logo--mono` and restores the invert filter for single-ink silhouette marks.
* *Opt-in pair:* `site.keys.header_logo_dark` renders a second `<img>` and CSS shows one asset per `html.dark-theme` state (no invert). Valentus demo playbooks set `logo.svg` + `logo-dark.svg` (anatomical heart outline).
* *Bugfix:* Partials looked up snake_case names on `site.keys`, but Antora camelCases playbook keys in the UI model (`header_logo_dark` → `headerLogoDark`, `dark_mode_navbar` → `darkModeNavbar`, …). Branding keys were silently ignored; templates now use camelCase.
* *Default assets:* Bundled outline heart uses explicit stroke colors (dark ink / light ink), not `currentColor`.
* *Docs:* Configuration keys + `header-logo.adoc` fixture gallery (brand and mono on mocked bars) so single-file strategies are visible without a second logo in the live chrome.
