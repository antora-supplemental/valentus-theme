== Context

Commit `3515896` replaced the home SVG chip with a plain `/` so the mast would copy as a path. The intent was only to drop a **Home** text control and keep real `/` separators — not to remove the house icon.

Readers also saw a literal `~` on the version **button**, which is Antora’s internal unversioned marker; the button should read **Version**, while the dropdown still teaches `~`.

== Changes

* Restore the SVG house icon inside `.adt-breadcrumb-home-link` (icon-only; no “Home” word).
* Restore kicker-chip sizing/border/background for the home control.
* Keep `<li class="adt-breadcrumb-sep">/</li>` trail separators for copyability.
* Kicker: `{{adt-version-label … fallback="Version"}}`; dropdown rows keep default `~`.
