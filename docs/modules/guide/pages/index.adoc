= Valentus Theme
:navtitle: Getting Started
:description: Composed Antora doc-site chrome with bundled dark mode — mast, header, layout, and VCS icons.

Valentus is debranded doc-site chrome for Antora 3.x: sticky header, breadcrumb mast with component/version pickers, sidebar layout, VCS provider icons, and the dark mode toggle.

The release `ui-bundle.zip` includes dark mode (successor to the former `antora-dark-theme` package).
Sites that need *dark mode only* on another theme should use link:https://github.com/antora-supplemental/antora-dark-mode[antora-dark-mode] — not this package as an overlay on itself.

Org product map: link:https://antora-supplemental.github.io/docs/docs/theme-products.html[Theme products^].

== Why Valentus

Beyond branding, Valentus ships ergonomics that stock Default UI / Lunr often miss (permalink hit area, sidebar scroll chaining, unclipped search, mobile font-size, Search or Ask omnibox, and more).
See xref:value-proposition.adoc[Value Proposition & Upstream Fixes] for the checklist and upstream GitLab trackers.
