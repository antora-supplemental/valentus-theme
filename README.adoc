Composed Antora doc-site chrome (color scheme via the chassis color-scheme extension).

== About The Project

Composed Antora doc-site chrome: breadcrumb mast, header, layout, VCS icons, the placed theme toggle, and the light/dark paint.
The color scheme *mechanism* (no-FOUC hook, persistence, system preference, toggle behavior) is the chassis extension link:https://github.com/antora-supplemental/antora-ui-chassis/tree/main/packages/color-scheme[`@antora-supplemental/color-scheme`] — add it to your playbook.

Successor to the former `antora-dark-theme` monolithic package — use the Valentus release `ui-bundle.zip` for the full stack.
`antora-dark-mode` is deprecated; its mechanism moved to `@antora-supplemental/color-scheme` and its palette to Valentus `site-paint.css`.

**Changelog:** link:CHANGELOG.adoc[CHANGELOG.adoc] and link:changelog-details/[`changelog-details/`].

**Value proposition / upstream fixes:** `docs/modules/guide/pages/value-proposition.adoc` — UX debt Valentus softens relative to Antora Default UI / Lunr, with GitLab trackers, for pitching this theme as a richer default.

**Versioning:** Public labels are `VALENTUS_SEMVER+antora.N` (example *3.0.0+antora.3*).
Valentus major tracks breaking chrome for theme modders; `+antora.N` tracks the Antora framework major.
Git tags stay pure semver (`v3.0.0`); pin URLs use those tags. Details: `docs/modules/guide/pages/version-pinning.adoc` and `supported-lines.json`.

== Installation

[source,yaml]
----
ui:
  bundle:
    url: https://github.com/antora-supplemental/valentus-theme/releases/download/v3/ui-bundle.zip
    snapshot: true
  supplemental_files: ./supplemental-ui-overrides   # optional branding only
antora:
  extensions:
    - require: "@antora-supplemental/color-scheme"
      toggle: placed
----

Pin the extension in `package.json`:

[source,json]
----
"@antora-supplemental/color-scheme": "github:antora-supplemental/antora-ui-chassis#color-scheme-v0.1.2&path:packages/color-scheme"
----

Add the GitHub topic `valentus-theme` on your playbook repository so dependents stay rediscoverable (`gh search repos --topic valentus-theme`). Guide: `docs/modules/guide/pages/github-topics.adoc`.

Optional overlay from git instead of the release bundle:

[source,yaml]
----
ui:
  bundle:
    url: https://gitlab.com/antora/antora-ui-default/-/jobs/artifacts/HEAD/raw/build/ui-bundle.zip?job=bundle-stable
    snapshot: true
  supplemental_files: ./path/to/valentus-theme/supplemental-ui
----

Both forms need the `@antora-supplemental/color-scheme` extension (above). `supplemental-ui/css/site-paint.css` holds the Default UI dark palette and toggle look; there is no vendored dark-mode copy any more.

== Usage

=== Demo

https://antora-supplemental.github.io/valentus-theme[GitHub Pages demo] (published from `main` via GitHub Actions) — *guide* plus link:https://antora-supplemental.github.io/valentus-theme/demo-pages/~/[demo-pages fixtures^] composed from link:https://github.com/antora-supplemental/demo-data[`demo-data`^].

Facto compose (client Mermaid, lightbox, SoftNav) lives in a **separate** demo: https://antora-supplemental.github.io/facto-stack/[Facto stack demo] — Valentus core stays lean.

Local preview requires at least one Git commit on `HEAD` (Antora reads `content.sources` from the repo). Then:

[source,shell]
----
pnpm install
pnpm build:local
----

=== UI modules

Composable chrome via `ui-modules/` and the orchestrator extension — see `ui-modules/README.adoc`.

=== Color scheme on other themes

Sites on a *different* theme bundle use `@antora-supplemental/color-scheme` (`toggle: auto`) plus that theme's own paint. The deprecated `antora-dark-mode` overlay is no longer needed.
