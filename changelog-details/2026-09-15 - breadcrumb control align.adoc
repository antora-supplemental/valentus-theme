= Breadcrumb mast control alignment
:description: Match home/component/version control heights and restore the home→component gap.
:page-audience: Theme maintainers and hub authors
:page-usage-context: After rebuilding against Valentus with this Unreleased fix
:page-orig-author: Ryan Johnson
:page-last-author: Cursor agent on behalf of Ryan Johnson
:page-last-edited: 2026-09-15

== Context

On hubs such as HCI Nerdz, the component kicker looked taller than Version and its label sat high in the chip. The home chip also sat flush against the component name even though Valentus already set `margin-inline-end` on `.adt-breadcrumb-home`.

== Cause

* Component and version kickers used different `font-size` / `line-height` / padding, so the flex boxes grew unequally and the label baseline drifted.
* Default Antora UI ships `.breadcrumbs li { margin: 0 }` at specificity `(0,1,1)`, which beat `.adt-breadcrumb-home` `(0,1,0)` and zeroed the intended gap.

== Changes

* Introduce `--adt-bc-ctrl-h` (1.75rem) for home link + both kickers (+ plain version).
* Lock kicker `height` / `min-height`, use `line-height: 1`, and flex-center `.adt-bc-kicker-label` / `.adt-bc-kicker-version`.
* Raise home gap specificity to `.adt-breadcrumbs > ul > li.adt-breadcrumb-home` and set `margin-inline-end: 0.45rem`.
