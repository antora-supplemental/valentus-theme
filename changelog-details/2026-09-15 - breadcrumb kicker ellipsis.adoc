= Breadcrumb component kicker ellipsis
:description: Show "…" when the component (or version) kicker label is wider than the chip.
:page-audience: Theme maintainers and hub authors

== Context

Long component titles in the mast kicker were clipped flush at the chip edge with no trailing ellipsis, even though `text-overflow: ellipsis` was already declared on `.adt-bc-kicker-label`.

== Cause

`2.0.32` switched the label to `display: inline-flex` so text sat vertically centered in the shared control height. `text-overflow` only applies to block containers with a constrained width and `white-space: nowrap`; on a flex container the label text becomes an anonymous flex item and the parent button’s `overflow: hidden` hard-clips without painting `…`.

== Changes

* `.adt-bc-kicker-label` / `.adt-bc-kicker-version` use `display: block`, `white-space: nowrap`, `flex: 1 1 auto`, and `min-width: 0` so the label shrinks beside the chevron and ellipsis paints.
* Vertical centering stays on the parent `.adt-bc-kicker` (`inline-flex` + `align-items: center` + locked `--adt-bc-ctrl-h`).
